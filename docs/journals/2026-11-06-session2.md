# セッション2の振り返り

- 端末が1台しかないことは、実機テストを止める理由にならなかった。指揮役がブラウザペインから相手役として参加し、届いた声を送り返すことで、ユーザーは自分の声が相手にどう聞こえるかを iPhone 1台で確かめられた。同じ回の音量の記録とユーザーの耳の両方で照らし合わせられたのも良かった
- 数値だけで結論を急がなかったのが効いた。最初の3回は「合図から声まで 1〜2.3 秒」で、話し始めの欠けを疑いかけた。しかしそれは、比較のために頼んでいた「1秒待ってから話す」と区別できない数字だった。「押した瞬間に数える」という、人の行動が決まる試験に変えたら、欠けは無いとはっきりした。計測の前に、測っているものが何で決まるのかを決めておく
- ユーザーは「ホーム画面に追加」を知らなかった。祭りの班長たちも同じだろう。アプリの出来とは別に、配り方と最初の案内が本番の成否を分ける
- 登録作業では、できること（組織とプロジェクトの入力）とできないこと（サインイン、パスワード）を最初に表で分けたので、途中で止まらずに進んだ
