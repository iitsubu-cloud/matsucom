# 2026-10-27: テーマ決定・要件の聞き取り・技術構成の調査

## 実装内容

- テーマ: 地域の秋祭りで、太鼓台のリーダーと3〜4班の班長が常時連絡を取り、互いの位置を地図で見るアプリ（本番 2027年10月）
- 要件の聞き取り（端末の混在、トランシーバー式、電波の弱い所あり、一斉・個別・呼び出し音、音声・文字・写真・ファイル）
- Sonnet 2体で中継サーバーとリアルタイム音声を並行調査 → 指揮役が7か所を公式で再確認 → 構成案を作成（docs/specifications/architecture-research-2026-10.md）

## 設計判断

- Web アプリ（画面を点けたまま前提）。画面オフで位置・音声が止まるのは OS の決まりで、Web からは許可を求める手段が無い
- 声はユーザーの選択でリアルタイム（参加者の多くはお酒が入って気が短い）
- 中継サーバーは Supabase Free。Firebase は 2026-02-03 から無料プランで Storage を使えない
